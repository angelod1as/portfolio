My first take on Static Site Generation was circa 2015, working with a bunch of designers-turned-developers at Folha de S.Paulo. We developed our own SSG engine with `gulp`, `grunt`, `webpack`, and some other stuff I can't remember. We had (for reasons) to work strictly with JavaScript, so Hugo or Jekyll weren't real solutions.

From there, I went with Gatsby for a long time (and the first version of this website was built using it), then moved to Next.js when I got tired of the amount of workarounds Gatsby needed — my first and only NPM package was a [Gatsby plugin](https://github.com/angelod1as/gatsby-plugin-html-comments).

## Astro is Fun

I'm not even believing I'm build a website with pseudo-common HTML. Of course, I'm doing it in `.astro` components, but the raw HTML is there with some good old CSS — yeah, the vanilla kind, not `tailwind` or something like that.

I'm building nice stuff and I didn't even install React yet!
