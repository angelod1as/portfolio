## From old to new

The old website had a bunch of sections in the homepage, and a lot of text.

With the urge of making it sleeker, I will need to... improve this. Make it smaller. More concise.

So, the decision was, following [Mitchell](https://mitchellh.com/writing)'s website inspiration, to have a sidebar with the following menu:

- About → This is the "homepage". It will have a concise version of my current homepage, a quick blog post listing, a quick projects listing, and whatever I think should come here. The focus is: direct.
- Blog → Blog posts index
- Projects → Projects index
- More → CV, contact, other info.

This menu will be expandable.
